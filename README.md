# Siddh Samarth - Cybersecurity Portfolio

A modern, performant portfolio website showcasing cybersecurity expertise, projects, and achievements.

## 🌐 Live Website

**🔗 [View Live Portfolio](https://siddhsamarth.in/)**

---

## Tech Stack

- **Framework**: Next.js 15.1.9 (App Router)
- **UI Library**: React 19.0.1
- **Language**: TypeScript 5.7.3
- **Styling**: Tailwind CSS 3.4.17
- **Animations**: Framer Motion 12.0.0
- **Icons**: Lucide React
- **Deployment**: Vercel

## Features

- 🎨 **Modern Dark Theme** - Cybersecurity-inspired design
- 🎭 **Smooth Animations** - Scroll-triggered and hover effects
- 📱 **Fully Responsive** - Optimized for all devices
- ⚡ **Performance Optimized** - Fast loading and smooth interactions
- 🎯 **Interactive Elements** - 3D tilt cards, rotating headlines, animated backgrounds
- 🔒 **Security Focused** - Showcasing SOC operations, threat detection, and security research

## Sections

- **Hero** - Rotating headlines with 3D background
- **Academics** - Education and training
- **About Me** - Core expertise and tools
- **Security Insights** - Security principles and methodologies
- **Certificates** - Professional certifications (8 categories)
- **Security Principles** - Privacy-first research approach
- **Experience** - Internships and field experience
- **Projects** - 6 featured cybersecurity projects
- **Skills** - Technical skills and technologies
- **Footer** - Links and contributor information

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/SiddhSamarth/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```
